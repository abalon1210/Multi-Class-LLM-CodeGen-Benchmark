Question: Write a function that iterates over each element in a list and adds it to a sum if it is even.
Output:
def sum_of_evens(lst):
  """
  Sums all even integers in a list.

  Parameters:
    lst (list[int]): List of integers.

  Returns:
    int: Sum of even integers.

  Example:
    >>> sum_of_evens([1, 2, 3, 4, 5, 6])
    12
  """
  
  total = 0
  for num in lst:
    if num % 2 == 0:
      total += num
  return total
